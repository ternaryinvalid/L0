# Проект: Демонстрационный сервис для отображения данных о заказах

Этот проект представляет собой демонстрационный сервис с простейшим интерфейсом, который отображает данные о заказах. Модель данных для сервиса приведена в конце задания.

## Задачи:

### 1. Развертывание PostgreSQL локально

Для начала необходимо развернуть PostgreSQL на вашем локальном компьютере(Docker).

### 2. Создание базы данных

1. Создайте свою базу данных в PostgreSQL.
2. Настройте пользователя для работы с базой данных.
3. Создайте необходимые таблицы для хранения полученных данных.

### 3. Разработка сервиса

1. Реализуйте сервис для работы с заказами.
2. Подключите сервис к Kafka и подпишитесь на топик `orders`.
   - Полученные данные должны записываться в БД.
   - Реализуйте кэширование данных в памяти (in-memory cache).
   - При прекращении работы сервиса необходимо восстанавливать кэш из базы данных.
3. Разработайте HTTP-сервер для выдачи данных по id заказа из кэша.
4. Создайте простой интерфейс для отображения данных о заказах по id.

## Требования

- PostgreSQL в Docker-контейнере для хранения данных.
- Kafka в Docker-контейнере для получения данных о заказа.
- HTTP-сервер для взаимодействия с пользователем.

## Работа
Веб-интерфейс будет доступен по адресу `http://localhost:8080`.
Отображение данных доступно по запросу `GET /order/{id}`.
