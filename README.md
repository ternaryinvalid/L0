Проект представляет собой выполнение следующего задания:
Необходимо разработать демонстрационный сервис с простейшим интерфейсом, отображающий данные о заказе. Модель данных можно найти в конца задания.

Что нужно сделать:

1.Развернуть локально PostgreSQL

2.Создать свою БД
  1.Настроить своего пользователя
  2.Создать таблицы для хранения полученных данных
  3.Разработать сервис

3.Реализовать подключение к брокерам и подписку на топик orders в Kafka
  1.Полученные данные записывать в БД
  2.Реализовать кэширование полученных данных в сервисе (сохранять in memory)
  3.В случае прекращения работы сервиса необходимо восстанавливать кэш из БД
  4.Запустить http-сервер и выдавать данные по id из кэша
  5.Разработать простейший интерфейс отображения полученных данных по id заказа
